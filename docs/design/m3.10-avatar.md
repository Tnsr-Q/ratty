# M3.10 Avatar — unified design for the five blockers

Synthesis of four adversarially-verified design chains (12 agents, all API claims
checked against vendored crate sources under `~/.cargo/registry/src/index.crates.io-*/`).
Conflicts between chains were resolved with the locked #23/#18 resolution text as
arbiter. Repo anchors are current as of `main` @ a58070f.

The four raw chain documents (full detail, every anchor), in this directory:
`m3.10-avatar-overlay-text.md`, `m3.10-avatar-longrun-protocol.md`,
`m3.10-avatar-trust-tier.md`, `m3.10-avatar-assets-wasm-budgets.md`. Where a
chain document and this file disagree, this file wins (§6 records each
reconciliation and why).

## 0. Premise corrections (what changed the solution space)

1. **The text stack is already compiled into the binary.** `parley_ratatui` does not
   *re-export* parley/swash, but it *depends* on them: `parley 0.10.0`,
   `skrifa 0.42.1`, `swash 0.2.9`, `fontique 0.10.0` are in Cargo.lock. Adding
   `parley = "=0.10.0"` as a direct dep is a lockfile no-op — zero new compiled
   code. `parley_ratatui::vello` re-exports vello wholesale (its `Scene::draw_glyphs`
   at vello-0.9.0/src/scene.rs:455 takes the same `FontData` parley's `Run::font()`
   returns — one `linebender_resource_handle` in the lock, zero conversion).
   The in-tree reference conversion is `paint_layout`
   (parley_ratatui-0.3.4/src/renderer.rs:982-1024).
2. **The avatar wire grammar already exists as stubs.** `AvatarSet/Gesture/Speak/Hide`
   variants at src/osc.rs:426-445, parse arms at :873-884, currently rejected
   `unsupported` by the `other =>` arm (src/ai.rs:289-300). There are zero working
   callers (grepped transmissions/site too) — the grammar can be redesigned freely.
3. **Execution-handle infrastructure half-exists.** `state.executions` is a live op
   (query_channel.rs:63 → macros::executions_state_value at :448); the locked #18
   reply grammar already carries `data=` on acks (`reply_sequence`/`parse_reply_body`,
   query.rs:386-464); `send_reply` already takes a payload param — only the ack drain
   hardcodes `None` (query_channel.rs:297). The extension is additive within v=1.
4. **The wasm GLB bail is a filesystem-staging problem, not a glTF problem.**
   bevy_gltf compiles wasm-clean with ratty's feature set; Bevy's `embedded://`
   asset source is an in-memory reader with no target cfg
   (bevy_asset-0.19.0/src/io/embedded/mod.rs, io/memory.rs), and its registry `Dir`
   is Arc-shared so bytes inserted at plugin-build time are visible to the reader.
5. **The decoded-runtime cap IS meaningfully build-verifiable.** A GLB's JSON chunk
   gives accessor counts (triangles), materials, images; PNG IHDR gives W×H without
   a decoder; decoded estimate = BIN bytes + Σ(W×H×4). `extensionsRequired` is
   rejected outright (bevy_gltf 0.19 compiles no Draco/meshopt —
   verified in bevy_gltf-0.19.0/Cargo.toml and gltf-json's ENABLED_EXTENSIONS).
   What is NOT verifiable (device GPU truth, mipmaps, animation cost) is named in
   the auditor's doc comment, not faked.

## 1. Bubble/typewriter overlay, fixed through camera movement (issue 1)

**Substrate: a second vello `Scene` → own render/present texture pair →
screen-space composite.** Never touches the terminal texture, so it cannot warp.

- Texture pair via the existing pub(crate) helpers `new_terminal_render_image` /
  `new_terminal_image` / `resize_terminal_image` (direct_render.rs:160-226), sized
  to the window physical framebuffer; 1×1 + `Visibility::Hidden` when idle.
- Second scene exchange cloned from `DirectTerminalSceneExchange`
  (direct_render.rs:69-146), rendered by a second render-world system in
  `RenderGraphSystems::Begin` `.after(render_terminal_frame)`, reusing the same
  `GpuRenderer` via `render_scene_to_texture_view`
  (parley_ratatui-0.3.4/src/renderer.rs:187) with `TRANSPARENT` base.
- Present via the existing `TerminalPresentMaterial` + `fullscreen_quad()` (both
  pub, present.rs) — the present shader's centering math is the identity when
  texture size == viewport size, so zero new shader code.
- Composite via a dedicated `AvatarBubbleCamera` (`Camera2d`, order 5,
  `ClearColorConfig::None`, own `RenderLayers`, `Msaa::Off`) — the `AiEffectCamera`
  recipe (effects.rs:341-354). Camera stack: 0 flat-2D → 1 terminal-3D → 5 bubble
  → 6 mascot → 10 effects wash (wash tints the avatar like everything else).
- **Two required edits to existing plumbing** (found by deep-read, easy to miss):
  scene/mod.rs:252-261 `camera_2d` filter needs `Without<AvatarBubbleCamera>` or
  3D modes deactivate the bubble; systems.rs:472 `present_query` needs
  `With<TerminalSprite>` or `sync_terminal_materials` rebinds the avatar quad to
  the terminal texture.

**Real text: direct `parley = "=0.10.0"` dep, not bevy_text/bevy_ui.** Honest
comparison ran both ways; bevy_ui loses on every declared axis (new compiled code
incl. a *second* parley 0.9 via bevy_text, wasm bundle growth, different AA than
the vello terminal glyphs, no tail/chrome primitives). Fonts: embed the DejaVu
Sans Mono regular+bold already shipped in assets/fonts/ (wasm already
`include_bytes!`es them at terminal.rs:369-372; hoist into a shared `src/fonts.rs`;
~680 KB native binary growth, wasm bundle unchanged). Register via
`fontique::Collection::register_fonts` exactly as parley_ratatui does internally.

**Typewriter: lay out once, reveal per cluster.** Cache one `parley::Layout` per
(text, wrap_px, font_px); each frame re-encode the scene painting only clusters
with `text_range().end <= revealed_bytes`, walking `visual_clusters()` and
accumulating advances for hidden clusters — ligatures never half-draw, RTL reveals
in logical order at correct visual positions, reveal progress survives re-wrap on
resize (byte offset, not glyph count). Speaker attribution chip is laid out
separately, bold, never typewriter-gated — identified from frame one.

**Mascot, screen-fixed:** dedicated `AvatarMascotCamera` (`Camera3d`, order 6,
fixed orthographic pose, own RenderLayers + dedicated light). RGP `c`-verb
machinery only writes `TerminalPlaneCamera` (systems.rs:2488-2581; filter at
scene/mod.rs:262), so the mascot cannot move with yaw/pitch/zoom/warp/Möbius *by
construction*. World units = logical pixels; the nine-anchor → world math mirrors
`cursor_pose`. glTF descendants get `RenderLayers` via the
`apply_instance_brightness` upward-walk pattern (systems.rs:1582-1639).
Choreographies (bob/tilt/lean/nod/spin) are named root-transform programs — the
cursor spin/bob math generalized (systems.rs:2752-2763); no AnimationGraph, per
the locked B-milestone scope. Speaking glow: vello radial disc in the overlay
scene behind the mascot rect, driven by the utterance envelope.

Status: design chain complete; its verifier died on a session limit, so I
re-verified the load-bearing claims by hand (present material pub, direct_render
helpers, `render_scene_to_texture_view`, `draw_glyphs(FontData)`, fonts on disk,
effect-camera recipe, stub grammar + `other =>` arm) — all confirmed. One
explicitly-gated risk: alpha fringing of vello output over a transparent base
through the `ALPHA_BLENDING` present material — eyeball at integration; fix is a
one-line `PREMULTIPLIED_ALPHA_BLENDING` material variant, not a redesign.

## 2. Long-running-op protocol (issue 2)

**The locked grammar already carries everything; what's added is one field and
semantics.** A long-running command's single `t=r;kind=ack` reply uses the
`ok=1` qualifier `code=started|queued` (the `deferred` precedent, query.rs:103-106;
unknown success codes are mandated-ignored, protocols/query.md:77-81) plus a
structured `data=` payload `{"id","position","eta_ms"}`.

- `AckOutcome` gains `payload: Option<serde_json::Value>`; the three constructor
  helpers (`ack_commit`/`ack_commit_qualified`/`reject`, query_channel.rs:194-250)
  add `payload: None` internally — **zero changes at the ~40 organ call sites**.
  New helper `ack_commit_long_running`. Drain loop (query_channel.rs:290-298)
  serializes the payload into `send_reply`'s existing payload param.
- **Execution handles minted by `QuerySession`** (which already owns the
  session nonce): `<nonce-hex>-<seq>`, so cross-restart staleness is detectable
  (`owns_execution_id` → `unknown-id` with an honest previous-session message).
  No central execution table: each organ owns its state; `state.executions`
  (widened, no new op) is the single merged projection; absence of a handle IS the
  completion signal (bounded-memory, poll-don't-notify — `t=e` stays reserved).
- **Fair bounded queue** in the avatar organ: 1 active, ≤4 pending global,
  ≤1 pending per agent, FIFO within agent. **Round-robin must be epoch-based**
  (serve the pending set snapshotted per rotation pass): the verifier proved the
  naive cyclic-successor rule has a worst-case start delay of ~64 minutes under
  adversarial admissions, not the documented ≤45 s. Epoch RR restores the hard
  `remaining(active) + 3 × MAX_UTTERANCE_MS` bound; test it adversarially.
- Position semantics (verifier fix): `position = pending utterances served before
  yours in rotation + (1 if active exists)`; 0 = speaking now.
- Errors: `busy` (reuse, doc extended), `agent-queue-full` (new),
  `text-too-long` (new), `not-owner` (reuse — its documented meaning is exactly
  the cancel-another-agent case). `nothing-active`/`unknown-id` doc comments gain
  one sentence each (verifier fix — they'd otherwise lie).
- Cancellation: `avatar.stop` (own current-or-queued), `avatar.cancel;id=<handle>`
  (owner-checked). Handles are transport-epoch metadata: a new
  `is_execution_control()` predicate keeps them out of recordings (recorder tap)
  and out of trusted config macros (loader refusal).
- `macro.play` retrofit: mints a handle, acks `code=started` +
  `{"id","position":0,"eta_ms"| "eta_frames"}` (instant mode honestly answers in
  frames — Time promises no frame duration at admission). `ExecutionView` gains
  `id`.
- `state.scene` gains the locked five fields exactly:
  `avatar: {visible, speaking, speaker, execution, queue_depth}` — **no utterance
  text**, ever; own text appears only in owner-scoped `state.executions` items.
- wasm (verifier fix): command acks surface through the raw `feed()`/
  `drain_input()` path via the shared codec; `RattySession.query()`'s promise map
  never sees command acks (only `query()` registers tokens). If a
  promise-returning command API is wanted later it is explicit new scope (and
  `try_resolve_pending` must then stop dropping `code=` on the ok path).

Verifier: needs-fixes → all seven findings have concrete fixes, folded in above.

## 3. Trusted scene-level capability tier (issue 3)

**Capability = ingress principal × out-of-band grant, named in the type system.**
New `src/capability.rs`:

```rust
pub enum SceneCapability { AvatarScene, SceneAmbient }
impl SceneCapability {
    pub fn granted_to(self, source: IngressSource, config: &AppConfig) -> bool {
        match source {
            IngressSource::Local => match self {
                SceneCapability::AvatarScene => config.trust.local.avatar_scene,
                SceneCapability::SceneAmbient => config.audio.allow_scene_ambient,
            },
        }
    }
}
```

- **The honesty clause is structural**: no `IngressSource::Trusted` variant
  (nothing could honestly construct one — the runtime.rs:36-43 doc is right that
  one PTY is one principal). A grant to `Local` is process-wide across every PTY
  writer, stated plainly in module doc + config doc + TOML comment — exactly what
  `allow_scene_ambient` already is. What the type system buys is the **exhaustive
  no-wildcard match**: when an authenticated transport adds an `IngressSource`
  variant, `granted_to` stops compiling until that transport's grants are decided
  explicitly. The wire can never self-escalate: grants live only in wire-immutable
  config (load-once, no hot reload), the wasm embedder's TOML (`start(canvas,
  config_toml)`, web.rs:315-322 — the page IS the trusted tier on wasm), and
  direct Rust API entry points (`insert_trusted` precedent, macros.rs:318-323).
  No grant command exists in the grammar; rejected: CLI grant flags, in-band
  grants, a stored Capabilities resource (config is the single truth).
- Config: `[trust.local] avatar_scene = true` (default true — single-tenant
  session directs its own scene, the ambient posture; multi-writer operators
  revoke). `allow_scene_ambient` stays at its key, routed through the spine —
  behavior-identical, proven by the existing sound tests passing untouched.
- **Enforcement at one choke point**: the avatar applier, `require_scene!` gate
  mirroring sound.rs:592-602. Covers wire, macro, bookmark, and rule paths
  identically because injected commands carry their owner's `source`. Rejection =
  `warn!` + `reject` → `ok=0;code=not-permitted` (the existing code whose doc
  comment is verbatim this semantics: "the caller's ingress tier does not carry
  the required capability" — no `not-authorized` synonym minted).
- Gated: `avatar.set`, `avatar.show` (new verb), `avatar.hide`,
  `avatar.speech.clear;ns=<other>`, `avatar.speech.clear;scope=all`.
  Ungated (ordinary tier): `avatar.speak`, `avatar.gesture`, bare
  `avatar.speech.clear` / own-namespace `ns=`, `avatar.stop`, `avatar.cancel`
  (owner-checked).
- #16: `is_scene_global` gains `AvatarSet|AvatarShow|AvatarHide` and
  scope-dependent `AvatarSpeechClear` — privileged macro classification, sealing,
  and the scene lock all propagate automatically (macros.rs:498-610). #21:
  zero code change — the allowlist is default-deny; tests pin the exclusion.
- `caps` gains a `trust` block reporting the caller's live grants (discoverable
  before attempting).
- Verifier fixes folded in: `Reset`'s ungated avatar-clear is now *argued* (reset
  is return-to-baseline, not scene control; hidden+empty is the default state;
  precedent: ungated reset already fades the ambient bed regardless of
  `allow_scene_ambient`, sound.rs:355-361/664-668) and pinned by a test;
  `drive_macro_playback → apply_avatar_commands` ordering edge added (same-frame
  invariant, macros.rs:680-706); `pub mod capability;` inserts before `cli`
  (alphabetical); protocols/avatar.md + `ratty-ai` CLI rows added to the manifest.

**Honest residue to be aware of:** with one namespace today, the capability tier
is real (config-revocable, type-expressed) but agent-vs-agent distinctions
(per-agent queue slots, `not-owner`, RR fairness) are dormant machinery exercised
by unit tests until an authenticated ingress lands. Same stance as the
per-namespace macro slots. Relatedly, `avatar.speak`'s displayed speaker label is
presentation-only decoration — authority and fairness key on
`source.namespace()`, never on anything in-band.

## 4. Mascot asset + wasm GLB (smaller issue A)

- **Designate `SpinyMouse.glb` as the M3 mascot** — already embedded in every
  binary (zero added bytes), 1,684,108 B (80% of the 2 MiB cap), 818 triangles,
  1 material, one 2048² PNG, `extensionsRequired: []`, self-contained (all
  measured byte-for-byte). It's the project's visual identity (spiny-mouse
  family; CairoSpinyMouse.obj is the default cursor). The dead `ai-helper.glb`
  parse default is removed. Curation follow-up (non-blocking): re-export with a
  1024² texture → decoded texture memory 16 MiB → 4 MiB, file ≈ 500 KB.
- **Semantic registry IDs, two-layer** (sound-organ pattern): wire vocabulary
  `osc::AVATAR_MODELS = &["mascot"]` shared with the CLI; terminal-side
  `AVATAR_REGISTRY` maps `mascot → SpinyMouse.glb + scale`. The wire never sees a
  filename (#12), and the C-milestone skinned asset is a registry-row change
  behind an unchanged command surface ("nothing in B is throwaway").
  Unknown names → new append-only codes `unknown-model` / `unknown-anchor` /
  `unknown-gesture` (`bad-asset`'s documented meaning is filenames; `no-anchor`
  means "scrolled away" — neither fits).
- **wasm: the real fix.** `seed_embedded_scene_assets(world)` — at
  `TerminalPlugin::build`, iterate `EmbeddedObjects`, insert every `.glb`
  byte-slice into Bevy's `EmbeddedAssetRegistry` (`embedded://objects/<file>`);
  the loader's GLB arm collapses to one cfg-free
  `ObjectSource::Gltf("embedded://objects/<file>")` — **embedded GLB loads
  identically on native and wasm**, the model.rs:352 bail and the native
  temp-file staging for embedded scenes are both deleted, and embedded-GLB wire
  objects (`object.add`) get wasm support for free. Every step source-verified
  (registry Dir is Arc-shared post-build; `pub mod embedded` has no cfg;
  bevy_gltf's loader is wasm-clean). What honestly stays native-only: external
  filesystem GLBs and RGP payload-bytes GLBs (out of #23 scope; documented seam —
  the same `insert_asset` call lifts payloads later with zero wire change).
  Contingency, explicitly gated: if the first-ever wasm glTF load hits a real
  blocker at the site-build gate, mascot-on-wasm defers with an honest
  `unsupported` while the bubble (which carries all attribution duties) stays
  fully functional — a reported deferral, not a silent degrade.

## 5. Build-verified budgets (smaller issue B)

`build.rs` gains `enforce_object_budgets()` mirroring `enforce_sound_budgets`
call-for-call, plus a dependency-free GLB auditor in `build/glb_audit.rs`
(serde_json added to build-deps — already lock-pinned 1.0.149, zero new crate
versions). Audits **every** GLB in assets/objects/ (all are wire-loadable):

- container integrity (magic/version/length/chunk walk);
- ≤2 MiB per asset, 4 MiB package (both shipped GLBs pass);
- triangles ≤5,000 (accessor counts; non-TRIANGLES modes fail);
- materials ≤8; images ≤4, PNG-only (**required** — only the `png` bevy feature
  is compiled, so a JPEG texture would fail at runtime), ≤2048/side via IHDR;
- `extensionsRequired` non-empty → fail with a re-export message (the locked
  "Draco/meshopt verified, not assumed" clause — verified absent from
  bevy_gltf 0.19's feature set, so the build check moves a guaranteed runtime
  failure to compile time);
- external `uri` in buffers/images → fail (can't audit or embed);
- decoded-runtime **estimate**: BIN bytes + Σ(W×H×4) ≤ 20 MiB, with its
  estimate semantics documented (SpinyMouse: 18,459,172 B = 88%). Device GPU
  truth/mipmaps/animation cost are named as unverifiable, not faked.

Verifier fixes folded in: `cargo:rerun-if-changed=build/glb_audit.rs` (without it,
edits to the auditor itself don't re-trigger the build — "build-verified" would
drift); the registry-lockstep test goes through a public seam
(`embedded_object_loadable` or a small accessor — `EmbeddedObjects` is private);
`ensure_scene_asset_path`'s remaining callers corrected (payload staging at
model.rs:555 and the staged-candidate fallback at :489-491; the external-file
branch inlines its own staging). The auditor is also unit-tested from
`tests/glb_budgets.rs` via `include!`, with synthetic failure corpora.

## 6. Cross-chain reconciliations (locked text as arbiter)

| Conflict | Resolution |
|---|---|
| Anchor vocabulary: 9 (overlay) vs 4 (assets) | **Nine** — locked text names corners, edge midpoints, center. Wire key stays `position` (the locked word); default `bottom-right` lives in `AvatarState::default()`, not the parser (stub parser's `top-right` and `ai-helper.glb` defaults both die). |
| Model ID: filename (overlay) vs semantic `mascot` (assets) | **Semantic** — survives asset re-export and the C-milestone swap; sound-organ precedent. |
| Privileged: avatar.set/hide privileged (overlay+trust) vs not (assets, ambient analogy) | **Privileged** — the locked text says it verbatim; assets chain overruled (its own doc names the one-line change path). |
| Speech policy: preemption (overlay) vs fair bounded queue (longrun) | **Queue** — locked #23 §2 is explicit; overlay chain didn't have that goal excerpt. Bubble renders the *active* utterance from the queue. |
| Text cap: 256 (longrun) vs 1000 | **1000 UTF-8 bytes** (locked). Over-budget rejects `text-too-long` (locked names TextTooLong first-class; overlay's `too-large` was the envelope code). |
| Speak wire keys: `rate`/`hold` (overlay) vs `duration` (longrun) | **`duration`** (locked: derives from text when absent, clamp 750 ms–15 s, pinned at admission). Reveal rate and hold derive internally from pinned duration; no extra wire keys in v1. |
| Unknown-name codes: `bad-asset`/`bad-anchor`/`bad-gesture` vs `unknown-*` | **`unknown-model` / `unknown-anchor` / `unknown-gesture`** — existing codes' documented meanings don't fit; append-only consts. |
| avatar.set validation: `embedded_object_loadable` (longrun) vs registry lookup | **Registry lookup** (`avatar_model_spec`) — composes with the semantic-ID and wasm fixes; the longrun verifier's native/wasm asymmetry concern dissolves once §4 lands. |

Merged wire surface (OSC 777 `ratty:` family, all riding the existing stub arms):

```
avatar.set[;model=mascot][&position=<9-anchor>][&dx=][&dy=][&scale=][&tok=]   privileged
avatar.show / avatar.hide                                                      privileged
avatar.gesture;gesture=bob|tilt|lean|nod|spin[&tok=]                           ordinary
avatar.speak;text=<pct ≤1000B>[&from=<label ≤64B>][&duration=<s>][&tok=]       ordinary, long-running ack
avatar.stop / avatar.cancel;id=<handle>                                        ordinary (owner-scoped)
avatar.speech.clear[;ns=<n>|;scope=all]                                        own: ordinary · wider: privileged
```

`from=` is a presentation label only — attribution authority is
`source.namespace()`; documented as unauthenticated decoration in
protocols/avatar.md.

## 7. Suggested implementation order (each slice independently green)

1. **Trust spine** (`src/capability.rs`, `[trust.local]`, sound conversion,
   `not-permitted` path) — no avatar dependency; sound tests prove expressiveness.
2. **Ack payloads + handles** (`AckOutcome.payload`, `ack_commit_long_running`,
   `QuerySession::mint_execution_id`, codes, `macro.play` retrofit) — lands
   #18 for macros before the avatar exists.
3. **Asset pipeline + wasm fix** (`seed_embedded_scene_assets`, registry,
   build.rs auditor) — also un-gates wire GLB on wasm, independently valuable.
4. **Avatar organ core** (state, queue, appliers, acks, `state.scene` /
   `state.executions` / `caps`, CLI, protocols/avatar.md).
5. **Rendering substrate** (fonts.rs, overlay exchange/camera/quad, parley text,
   mascot camera + choreography + glow).
Gates per repo rules: clippy `-D warnings`, full tests, release build, wasm
build, plus the two manual gates (blend fringing; site-build mascot load).
